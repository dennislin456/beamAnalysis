# 雙光斑分析模組功能需求書

## 1. 目的與範圍

本文件定義 **BeamAnalysis** 專案中 **DataRay M2 Batch** 分頁所用之雙光斑（above／below）分析模組需求與演算法規格。

| 項目 | 說明 |
|------|------|
| 主要使用者 | 批量 M2 後處理、光斑距離量測 |
| 核心模組 | `main/shared_components.py` → `find_dual_peak_valley_y` 等 |
| UI 整合 | `main/tab_batch_m2.py` |
| 修正紀錄 | [雙光斑波谷誤判與外圍散射修正.md](雙光斑波谷誤判與外圍散射修正.md) |
| 內切圓後續 | [inscribed_circle.md](inscribed_circle.md) |

本專案為離線 Excel／矩陣分析工具，不含即時取像。

---

## 2. 功能概述

對單張 **M2 強度矩陣**：

1. 沿最佳縱切 X 取 1D profile。
2. 以 **最佳局部雙峰對** 找波谷 Y（切分線）。
3. 依切分線分成 above／below 半區。
4. 各半區在 **自動定位帶** 內（可選 ROI 相交）以使用者選定模式定位中心。
5. 計算 above→below 距離（px／µm，DataRay pitch = **5.5 µm／px**）。

---

## 3. 問題背景（舊版缺陷）

舊版以「全域 prominence Top-2 雙峰」配對，常見失敗模式：

| 現象 | 後果 |
|------|------|
| 外圍強散射形成第三峰 | 主峰 + 散射被配成雙峰 |
| 波谷落在雙峰**之外** | 切分錯誤，距離被拉大（現場可達 ~800–1247 µm） |
| ROI 僅裁縱切剖面 | 半區中心仍掃全圖，散射可成 above／below 之一 |
| `min_peak_distance` 被硬下限蓋掉 | UI 設 5 px 仍可能併峰 |

詳細根因與數值對照見 [雙光斑波谷誤判與外圍散射修正.md](雙光斑波谷誤判與外圍散射修正.md)。

## 4. 演算法規格

### 4.1 波谷：最佳局部雙峰對

實作：`_find_dual_peak_valley_detail`（`shared_components.py`）

| 步驟 | 說明 |
|------|------|
| 1 | 1D profile 平滑（預設窗長 7） |
| 2 | 找局部極大，合併距離 < `min_peak_distance` 的峰 |
| 3 | 以強度 ≥ 35% 全局峰的 anchor，在 `max_pair_sep` 窗內找伴峰 |
| 4 | 配對分數 = 強度 × 平衡 × 波谷對比 × **銳度** × **緊緻度**（不獎勵大間距） |
| 5 | 波谷 = 兩峰之間 `argmin`，clip 至 `[peak_lo, peak_hi]` |
| 6 | 分數接近（≥ 82% best）時偏好 **較小 sep** 的配對 |

**保證：** `peak_lo < valley < peak_hi`，波谷不會落在雙峰之外。

`max_pair_sep` 由 `_estimate_max_pair_sep` 依 FWHM 推估，硬上限約 **48–80 px**（可經 Expected Distance 覆寫）。

### 4.2 縱切 X 選擇

無 ROI 時：`_best_cut_x_for_valley` 在亮欄位掃描，選局部雙峰對比最強的切線。

有 ROI 時：在框內以質心（50% 門檻、最大連通）估 seed X，再取 profile。

### 4.3 自動定位帶（無 ROI 抗散射）

找到雙峰對後產生 `locate_bounds = (x0, y0, x1, y1)`（全圖半開區間）：

- Y：雙峰 Y ± pad（pad ≥ 8 px，約 `max_pair_sep / 4`）
- X：`cut_x ± pad`

M2 Batch 之 above／below 定位（內切圓、質心等）在 **切分半區 ∩ locate_bounds** 內執行，遠距散射不在帶內則無法成為中心。

### 4.4 波谷搜尋框選（選用）

UI：`chk_batch_valley_roi` + XYWH spinbox。

啟用時：

- 質心 seed、縱切 profile、定位帶 **皆與 ROI 矩形相交**
- 語意：**centroid + valley**（非僅裁剖面）

預設 **關閉**；自動化流程依最佳局部雙峰對即可，ROI 為極端案例備援。

### 4.5 Expected Distance（選用）

UI：`Expected Distance (µm) Min / Max`（0 = 不限制）。

以 `pixel_pitch_um`（M2 Batch 預設 5.5）換算為 `sep_lo_px`／`sep_hi_px`，過濾配對候選，抑制偶發 **~700 µm**（dual + 散射近緣）誤判。

建議：真雙峰距離約 155 µm 時設 **80 ~ 250 µm**。

## 5. API 規格

### 5.1 `find_dual_peak_valley_y`

```python
find_dual_peak_valley_y(
    matrix,
    cx=None,
    col_half_width=2,
    smooth_win=7,
    min_peak_distance=5,
    roi=None,                          # (x, y, width, height) 或 None
    expected_distance_min_um=None,
    expected_distance_max_um=None,
    pixel_pitch_um=5.5,
    max_sep_cap_px=None,
)
```

**回傳 dict：**

| 鍵 | 型別 | 說明 |
|----|------|------|
| `valley_y` | float | 波谷 Y（全圖座標） |
| `cx` | float | 縱切 X（全圖座標） |
| `peak_ys` | tuple 或 None | 雙峰 Y `(y_lo, y_hi)` |
| `profile` | ndarray | 原始縱切（未扣背景） |
| `roi` | tuple 或 None | 實際 ROI `(x0,y0,x1,y1)` 半開 |
| `max_pair_sep` | float | 伴峰窗寬（px） |
| `locate_bounds` | tuple 或 None | 定位帶 `(x0,y0,x1,y1)` 半開 |

### 5.2 `intersect_half_with_locate_band`

```python
intersect_half_with_locate_band(matrix, split_y, half, locate_bounds=None)
# half: "below" | "above"
# → (submatrix, x_offset, y_offset)
```

## 6. UI 需求（M2 Batch）

| 控制項 | 預設 | 說明 |
|--------|------|------|
| 波谷搜尋框選 | 關 | centroid + valley 約束 |
| ROI X/Y/W/H | 0/0/200/200 | 啟用框選後有效 |
| Expected Distance Min/Max | 0 / 0 | µm；0 表示不限制 |
| 光斑定位模式 | 質心 | 含內切圓、I² 質心等（見 inscribed_circle.md） |

狀態列顯示：切分波谷 Y、縱切 X、雙峰 Y、框選範圍。

## 7. 驗收準則

| ID | Given | When | Then |
|----|-------|------|------|
| AC1 | 含遠距散射 M2 矩陣，ROI 關 | `find_dual_peak_valley_y` | 波谷在真雙峰之間；`peak_ys` 合理 |
| AC2 | 1D 剖面雙峰 + 遠散射第三峰 | `_find_dual_peak_valley_detail` | `peak_lo < valley < peak_hi` |
| AC3 | ROI 開且包住雙峰 | 分析 | `locate_bounds` 與 ROI 相交 |
| AC4 | Expected Distance 80–250 µm | 散射合成圖 | 雙峰 sep 落在範圍內 |
| AC5 | M2 Batch 重算 | 關 ROI | 十字落在主光斑，非散射區 |

## 9. 已知限制

| 項目 | 說明 |
|------|------|
| 超大雙峰間距 | 窗寬硬上限約 80 px；超距請設 Expected Distance 或調 `max_sep_cap_px` |
| 散射與雙峰空間重疊 | 1D 縱切法可能劣化；需改善光學／取像 |
| Basler 分頁 | 未整合本模組；若需同級行為可另開任務 |
| DataRay Batch（M1+M2） | 仍以 M1 Y 切分，不走本波谷路徑 |
