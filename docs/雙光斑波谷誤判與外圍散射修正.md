## 1. 問題概述

M2 雙光斑分析（`find_dual_peak_valley_y` 及同源演算法）在含外圍散射的矩陣上常出現：

1. **外圍嚴重光散射**（熱圖寬幅、破碎高亮區；縱剖面多出第三個寬峰）。
2. 演算法把「主雙光斑」與「遠距散射」當成一對雙峰，**波谷落在雙峰之外**（雙光斑與散射之間的深谷）。
3. 上／下半區定位掃**全圖半區**，散射區被標成 above／below 之一，距離被拉大（現場約 **1247 µm**；散射合成測資無 ROI 時約 **807 µm**）。
4. 舊版 ROI **只裁波谷縱剖面**，半區中心定位仍不受限；自動化流程不應每次手動設框。

此問題直接影響雙光斑距離可信度與批量量測可用性。

---

## 2. 修正目標

1. **波谷必須落在所選雙峰區間內**（最佳局部雙峰對的中間），不得落在雙峰之外。
2. **自動化預設可不設波谷搜尋框選** 仍能抗遠距散射。
3. 框選若啟用，應同時約束 **波谷搜尋與中心定位**（centroid + valley）。
4. 以單元測試量化改善前後行為。

---

## 3. 根因分析

### 3.1 舊波谷配對邏輯

```text
找所有局部極大 → 兩兩配對評分（曾用 weaker × sep）→ 取最高分 → 其間 argmin 為波谷
```

問題：

- `× sep`（或等價「偏好大間距」）讓 **主峰 + 遠距散射** 分數高於 **真正靠近的雙光斑**。
- `min_lobe_sep` 曾被抬成 `max(12, n//20)`，UI `Min peak distance = 5` 形同無效，近距雙峰易被合成一峰，再被迫去抓遠峰。

### 3.2 波谷搜尋框選作用範圍不足

| 步驟 | 舊行為（開框選） | 問題 |
|------|------------------|------|
| 縱切找波谷 | 剖面裁在框內 | 框內仍可能配錯峰；且自動化不想依賴框 |
| 半區 mask／內切圓／質心 | **全圖** `y < valley`／`y > valley` | 波谷一旦偏到「雙峰↔散射」之間，散射必成其中一心 |

現場證據：距離標註 **1247.4 µm ≈ 227 px**，大於搜尋框高 **220 px** → 至少一點必在框外，與「半區不受框選限制」一致。

## 4. 方法比較與選型

| 方法 | 作法摘要 | 優點 | 缺點 | 結論 |
|------|----------|------|------|------|
| 全域雙峰配對（舊） | 全剖面峰兩兩評分，常獎勵大間距 | 實作簡單 | 遠距散射易勝出；波谷常在雙峰外 | **淘汰** |
| 手動波谷搜尋框選 | 框內才搜尋／定位 | 現場可控 | 自動化需每料設框 | **保留為選用備援** |
| 全域強度 Top-2 | 取最高兩峰再切谷 | 極快 | 散射亮於次峰即失敗 | **不採用** |
| **最佳局部雙峰對** | 各強峰只在 FWHM 推得的 `max_pair_sep` 窗內找伴峰；波谷嚴格夾在該對之間；無 ROI 時半區自動限在雙峰鄰域 | 不依賴 ROI；波谷保證在雙峰內；抗遠距散射 | 雙峰間距 > ~100 px 可能需調窗 | **採用** |
| 雙高斯／模型擬合 | 擬合兩高斯中心與谷 | 物理語意清楚 | 成本高、易不穩 | **過重，本版不做** |

**選型決議：** 採 **最佳局部雙峰對**；波谷搜尋框選保留為進階手動覆蓋，非自動化前置條件。

## 5. 改善作法

### 5.1 波谷：最佳局部雙峰對

實作於 `main/shared_components.py`：

1. 縱剖面平滑後找局部極大。
2. 以每個夠強的峰為錨點，僅在 `max_pair_sep`（由該峰 FWHM 估計，硬上限約 48～80 px）內找伴峰。
3. 配對分數：強度 × 平衡 × 波谷對比 × 銳度 × 緊緻度（**不**獎勵大間距）。
4. 取分數最高的一對；波谷 = 兩峰之間的 `argmin`，並 clip 在 `[peak_lo, peak_hi]`。

保證：**波谷 ∈ (peak_lo, peak_hi)**，不會落在雙峰之外。

### 5.2 無 ROI 時的自動定位帶

找到雙峰對後：

- 以雙峰 Y ± pad 形成定位帶 Y 範圍；
- X 方向以 `cut_x ± pad` 收窄；
- above／below 定位在 **切分半區 ∩ 定位帶** 內執行。

遠距散射即使更亮，也不在定位帶內，無法成為中心。

### 5.3 波谷搜尋框選（選用）語意對齊

啟用 `chk_batch_valley_roi` 時：

- 質心 seed、波谷縱切、定位帶 **皆與框相交**；
- 符合 centroid + valley 精神，並約束半區定位。

### 5.4 主要變更檔（BeamAnalysis）

| 路徑 | 變更 |
|------|------|
| `main/shared_components.py` | 局部雙峰波谷、自動定位帶、框選半區夾取 |
| `main/tab_batch_m2.py` | M2 Batch UI、定位帶整合、Expected Distance |
| `main/test_spot_analysis.py` | 散射／無 ROI／近距雙峰測試 |

## 7. 驗收準則

- **無框選自動化**
  - **Given** M2 矩陣含遠距散射，波谷搜尋框選 = 關
  - **When** M2 Batch 分析
  - **Then** `valley_y` 位於兩光斑之間；距離接近真雙峰距離；中心不落在散射區

- **波谷幾何約束**
  - **Given** 縱剖面存在雙峰 + 遠距第三峰
  - **When** `_find_dual_peak_valley_detail`
  - **Then** `peak_lo < valley < peak_hi`，且該對為局部最佳雙峰（非主峰+散射）

- **框選備援**
  - **Given** 框選開啟且 XYWH 包住雙峰、排除散射
  - **When** 分析
  - **Then** 中心座標落在框內（半區 ∩ 定位帶 ∩ ROI）

---

## 8. 操作建議

1. **預設**：波谷搜尋框選 **關閉**，依賴最佳局部雙峰對。
2. 極端情況（雙峰極淡、散射與雙峰幾乎貼在一起）：再開框選包住雙峰作為備援。
3. 若光學上雙峰 Y 向間距長期 **> ~100 px**，需評估放大 `max_pair_sep` 硬上限（見 `_estimate_max_pair_sep`）或設定 Expected Distance。

## 9. 已知限制與後續

| 項目 | 說明 |
|------|------|
| 超大雙峰間距 | 預設窗寬硬上限約 80 px；超距雙峰請設 Expected Distance 或調 `_estimate_max_pair_sep` |
| 散射與雙峰重疊 | 空間上無法分離時，任何 1D 縱切法都可能劣化 |
| Basler 分頁 | 未整合本演算法；若需同級行為可另開任務 |
| 效能 | 最佳局部雙峰對為 O(峰數×窗內)，峰數有上限，批量後處理可接受 |

### 9.1 偶發 ~700 µm 誤判（v1.1 補強）

**機制**：伴峰窗若偏大，可能把「真雙峰之一 + 散射近緣」配成對（約 120 px × 5.5 ≈ 660–700 µm），雜訊下偶發。

**已再加強（2026-08-26）**：

1. 配對分數加入 **峰銳度（FWHM）** 與 **緊緻度（sep vs 峰寬）**；近分數時偏好小間距對。
2. 伴峰窗硬上限降為約 **48–80 px**（仍保 floor≈40，覆蓋典型 ~28 px 雙峰）。
3. 次峰絕對強度須 ≳ 全域峰 40%，避免散射內部假雙峰。
4. **Expected Distance [min, max] µm** 接入選峰。建議約 `80 ~ 250`（真值 ~155 µm 時）。
