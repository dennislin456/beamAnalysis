# 一維投影雙光斑演算法說明（客戶報告版）

文件用途：說明 Basler 短／長曝光雙光斑分析中「一維投影＋微分」演算法的處理步驟與結果解讀。  
**本文件不含數學公式**，僅描述流程與概念。

範例資料：`basler/test/700 um`，配對 **pair 001**（短曝光＋長曝光）。

---

## 1. 要解決什麼問題

量測時會同時取得：

- **短曝光影像**：主光斑清楚，適合當「上光斑」定位基準  
- **長曝光影像**：可看見較弱的**下光斑**（伴斑），但主斑往往過亮、外圍有散射

目標是在長曝光上穩定找出**下光斑中心**，並計算與短曝光上光斑的距離（單位：μm）。

---

## 2. 演算法概念（一句話）

> 先用短曝光鎖定上光斑位置，再在長曝光上沿雙斑大致共軸的方向切一條長條區域，把每一列的亮度左右加總成一條「上下方向的亮度曲線」，從曲線上辨認主峰與下峰，最後再回到影像上精修座標。

---

## 3. 處理步驟

### 步驟 1：短曝光抓上光斑

1. 對短曝光影像做背景扣除與相對峰門檻  
2. 取最大連通亮區的強度質心  
3. 得到上光斑座標（亞像素）

此點作為後續長曝光搜尋的**錨點**。

### 步驟 2：在長曝光上框出搜尋條帶

1. 以上光斑為中心  
2. 框出一條**垂直長條 ROI**（預設寬約 160 px、高約 512 px）  
3. 條帶方向對齊「上光斑 → 下光斑」的軸向

用意：只在雙斑可能出現的狹長區域內分析，減少畫面其他散射／雜訊干擾。

### 步驟 3：水平加總 → 一維亮度剖面

在條帶內：

1. 每一列（固定 Y）把該列左右像素亮度加總  
2. 扣除剖面背景（列加總的中位數）  
3. 得到一條「Y 對亮度」的曲線（水平加總剖面）

主光斑在曲線上會形成**高而明顯的主峰**；下光斑形成**較弱的第二峰**。

### 步驟 4：平滑剖面並找峰

1. 對剖面做輕度平滑（預設平滑窗約 7～8，不可過大）  
2. 用曲線升降變化找出局部峰  
3. 靠近短曝光錨點的峰 → 記為**主峰（上光斑）**  
4. 在主峰下方、排除主峰本體影響後，評選最適合的峰 → **第二峰（下光斑種子）**

說明：平滑窗若設太大，兩峰容易被糊成一個，導致找不到下光斑。

### 步驟 5：回到影像上精修座標

僅有 1D 峰位還不夠：

1. **上光斑**：在主峰附近小範圍做 2D 質心精修  
2. **下光斑**：在第二峰附近取亮核，精修 X／Y（避免被單側拖尾或散射拉偏）

輸出兩個亞像素中心點。

### 步驟 6：計算距離

1. 計算短曝光上光斑 → 長曝光下光斑的像素距離  
2. 依像素間距換算為實際距離：  
   **μm = 像素距離 × 3.45**

---

## 4. 軟體操作摘要（Basler 雙曝光分頁）

1. 匯入資料夾（奇數檔＝短曝光、偶數檔＝長曝光）  
2. 選擇一組配對載入  
3. 演算法選「**一維投影＋微分**」  
4. 建議參數起點：  
   - 短曝光門檻：約 20%  
   - 條帶寬 × 高：160 × 512  
   - 剖面平滑窗：7～8  
   - 最小峰距：約 12 px  
5. 按 **Apply** 取得上／下光斑與距離  

可選：先啟用 color scale，將低於雜訊門檻（常用 256）的像素歸零，有助抑制背景碎斑。

同資料集（`test/700 um`）批次驗證時，兩斑距離約 **~590 μm**（依 pair 與參數略有差異）。

---

## 5. 適用與注意

**較適合**

- 上、下光斑大致上下排列（軸向雙斑）  
- 下光斑偏弱，但在長曝光剖面仍可形成可辨識的第二峰  
- 需要比單純全圖質心更穩定的下光斑定位  

**使用時請注意**

- 短曝光錨點需大致落在雙斑軸上  
- 平滑窗勿過大（例如 50），否則雙峰易合併  
- 長曝光若把「black」設太高，可能把弱下斑裁掉  
- 側向第三斑／強干涉時，可適當縮小條帶寬  

---

## 6. 與其他演算法的差異（簡表）

| 演算法 | 重點 |
| --- | --- |
| 質心／門檻 | 短、長各抓一個亮核；弱下斑易被主斑主導 |
| **一維投影＋微分（本文件）** | 用軸向剖面找主峰／下峰，再 2D 精修；弱伴斑較穩 |
| 高斯濾波 | 長曝光先平滑，再於下方帶抓下斑；幀間很穩，距離可能略偏短 |
