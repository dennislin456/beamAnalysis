## 圖 3｜①～③ 剖面與主峰（左：影像｜右：1D）

```text
  長曝光 + ROI 框              profile(y)
  ┌──┬──────┬──┐              強度
  │  │ ████ │  │               ▲
  │  │ ████ │  │  水平加總      │    ★ 主峰 (hint≈短曝光 Y)
  │  │ ░░░░ │  │  ─────────►   │   /
  │  │ ▒▒▒▒ │  │               │  /
  │  │ ▒▒▒▒ │  │               │ ★ 第二峰候選…
  └──┴──────┴──┘               └────────► Y（向下）
```

**① ROI：** 以短曝光 `(cx,cy)` 為中心，寬×高條帶。  
**② 投影：** `profile(y) = max(列加總 − median, 0)`  
**③ 微分：** 平滑 → `dy` 正→負零交越 → 峰列表 → hint 鎖主峰 `y_p`

## 圖 4｜④ 第二峰怎麼選

```mermaid
flowchart TD
  P[主峰 y_p] --> W[量核心寬 core_w<br/>0.65×峰頂]
  W --> X[排除帶 exclude]
  X --> S{只搜下方?<br/>Y ≥ y_p + exclude}
  S -->|是| C[候選微分峰]
  C --> N[NEAR / MID / FAR 評分]
  N --> Y[分數最高 → secondary_y]
  S -->|無合格| B[後備：下方局部峰 / argmax]
  B --> Y
```

| 模式 | 距離比 `sep/core_w` | 評分重點 |
|------|---------------------|----------|
| NEAR | ≤ 2.2 | 振幅 × contrast² |
| FAR | ≥ 3.8 | 振幅 × 振幅比 |
| MID | 中間 | 兩式取高 |

## 圖 5｜⑤ 2D 精修（現行）

```mermaid
flowchart LR
  subgraph PRI[主峰／上光斑]
    P1[亮核 X + 短曝光軸折衷] --> P2[窄窗 2D 質心]
    P2 --> P3[軟彈簧穩 X]
  end
  subgraph SEC[第二峰／下光斑]
    S1[波谷外 Y 帶] --> S2[亮核質心 = x_seed<br/>core_frac 0.55]
    S2 --> S3[X 直接用 x_seed]
    S1 --> S4[2D 質心主要定 Y]
    S4 --> S5[Y = α·1D + 1−α·2D]
  end
```

| | 上光斑（主峰） | 下光斑（第二峰） |
|--|----------------|------------------|
| **X** | 亮核與短曝光軸折衷 → 窄窗質心 | **亮核質心**（不拉藍線） |
| **Y** | 2D 質心 | 1D 種子與 2D 混合 |
| **窗** | 主峰附近對稱 | 靠主峰側裁到波谷、外側加長 |

## 一頁版文字稿（口條／註解）

1. **短曝光**先抓中心，當軸心。  
2. **長曝光**框長條 ROI，每列水平加總成 1D 剖面。  
3. **微分找峰**，用短曝光 Y 鎖定上光斑。  
4. **只往下**找第二峰，NEAR／FAR 打分選下光斑 Y。  
5. **精修**：上斑窄窗質心；下斑 X 跟亮核、Y 跟 1D／2D 混合。  
6. 輸出兩點十字。
