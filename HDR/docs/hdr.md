# HDR 測試

對齊程式：`hdr_test.py`、`hdr_algorithms.py`、`mertens_local.py`（2026-10-20）

在 `beamAnalysis/HDR` 執行 `python hdr_test.py` 開啟。依賴見同目錄的 `requirements.txt`。這是獨立測試視窗，用來比較 Debevec、Robertson、Mertens、Mertens 自寫。合成、相減、補值、分析都不讀這裡的結果。前三個在 `hdr_algorithms.py`；自寫 Mertens 在 `mertens_local.py`。載入、高斯模糊、color scale 和科學記號輸入在 `common` 套件，不再讀 `FourStepAdj`。

可只勾選一張影像按「計算」畫熱圖和剖面（只做輸入前處理，不跑 HDR）。兩張以上、同一場景、不同曝光、尺寸相同時才跑演算法。Debevec 和 Robertson 先估計相機響應，再合成輻射圖。兩種 Mertens 做曝光融合，不產生輻射圖，也不使用曝光時間。計算順序見 `hdr_flow.md`。只加入一張且畫面上還沒結果時，載入後會自動顯示。

## 演算法

輸入先變成 8-bit。檔案本身是 8-bit 就直接用；其他檔案用「滿量」做 `像素 / 滿量 × 255`，再裁到 0–255。滿量預設 4095，這套相機可改成 4000。各張共用同一個滿量。OpenCV 的三種會把灰階複製成三個相同通道再計算，結果取回一個通道。自寫 Mertens 灰階保持單通道。曝光時間先從 us 換成秒；Debevec、Robertson 用各張的比例。

### Debevec

用多張不同曝光估計相機響應曲線，再把每張還原成輻射後合成。曝光時間不能全部相同。時間如何進入曲線、以及如何還原成輻射圖，見 `hdr_flow.md`。

- 樣本數：從影像裡抽出來估計響應曲線的像素數。少一點曲線較粗，多一點較貼這些影像，也比較慢。預設 70，範圍 1–100000。
- lambda：懲罰曲線彎來彎去的強度。調大，曲線更平滑；調到 0，幾乎不懲罰。預設 10，範圍 0–1000。
- 隨機抽樣：勾選後每次換一組樣本位置。不勾時用固定位置，同一組影像和參數會得到同一條曲線。預設不勾。

左下方畫出響應曲線。橫軸是 8-bit 像素 0–255。

### Robertson

同樣先估計響應曲線，再合成輻射圖，估計方式是疊代。曝光時間不能全部相同。

- 疊代次數：響應和輻射互相更新的次數上限。次數多，有機會更收斂，也更慢。預設 30，範圍 1–10000。
- 收斂門檻：相鄰兩次結果的變化小於此值就停止。調小會算得更細，調大較早停。預設 0.01，範圍 1e-8–10。

有估出曲線時，左下方一樣畫響應曲線。

### Mertens

把多張曝光融成一張看起來較均衡的圖。不估計響應，不使用曝光時間，所以各張時間相同也可以算。結果是融合圖，不是輻射圖。金字塔重建若低於 0，該像素先改成 0，再乘 255，回到 8-bit 尺度。大於 255 的值保留。

- 對比：偏好局部對比高的像素。調高，邊緣和細節較容易被留下；調到 0，不看對比。預設 1，範圍 0–20。
- 飽和：偏好色彩較鮮的像素。調高，彩色區域較容易被留下；調到 0，不看飽和。預設 1，範圍 0–20。灰階三個通道相同，飽和度是 0，這個權重幾乎不作用。
- 曝光：偏好亮度接近中灰的像素，壓過太暗和太亮的像素。調高，這個偏好變強；0 表示不看曝光好不好。OpenCV 預設是 0，範圍 0–20。

Mertens 沒有響應曲線，左下方標題是「Mertens 沒有響應曲線」。

### Mertens 自寫

權重公式跟 OpenCV Mertens 同一套想法，融合用自己寫的拉普拉斯金字塔，程式在 `mertens_local.py`。細節見 `mertens_local.md`。

- 對比、飽和、曝光：作用和上面的 Mertens 相同。預設 1、1、0。
- sigma：中灰鐘形寬度。預設 0.2（和 OpenCV 寫死的寬度相同），範圍 0.01–2。調小只留更接近中灰的像素；調大則較寬的亮度都會被留下。

灰階單通道時不乘飽和，所以調飽和不會因浮點殘差改熱圖。融合後小於 0 的像素先改成 0，再乘 255。大於 255 的值保留。沒有響應曲線，左下方標題是「Mertens 自寫 沒有響應曲線」。

## 載入

「加入檔案」可選 `.npy`、`.png`、`.bmp`、`.tif`、`.tiff`、`.csv`。灰階或 RGB 都可以。帶透明通道時去掉第四通道。檔名含獨立一段 `merged` 的融合成品（例如 `..._merged_YYYYMMDD_HHMMSS.npy`）不載入。按鈕有「載入父資料夾」、「載入主資料夾」、「加入檔案」、「調整範圍」、「清空」。

視窗由左到右是融合功能區、分析功能區、畫布。融合與分析各有獨立的直向捲軸。畫布統一用分析畫面；左上角是 log、abs、高斯模糊，色條上下限和色彩三角留在畫布並與融合匯出共用。輸入框用滾輪滑過時不改數值。

「載入父資料夾」選一層父目錄，底下每個子資料夾是一個點位（名稱如 `X0_Y90.85`），依名稱做數字排序。會跳出視窗勾選一個點位（不可多選）；之後可用「選擇點位」再換。切換後重載該點位影像並再選計算範圍，倍率、color scale、勾選與否、演算法、高斯模糊等參數會保留。在某一點位「移除」的曝光時間，切換其他點位時不會再自動載入（重新載入父資料夾或清除曝光列後才恢復）；移除後會清掉舊的批次結果，避免仍用已移除曝光的張數（例如 10000us 300 張）去跑。批次融合只跑目前點位，筆數只看**目前勾選**的曝光。

「載入主資料夾」直接載入單一點位／曝光資料夾。先看子資料夾名稱裡的曝光時間，沒有子資料夾時改讀資料夾裡的檔名。時間寫成 `500us` 這種形式，不限於 20／50／500… 等預設值；檔名或資料夾名裡的數字＋`us` 都會自動偵測成一列。每個曝光取排序後的同一筆。「主資料夾」在父資料夾模式顯示父目錄名稱，否則顯示目前載入的資料夾；分析區顯示目前點位／主資料夾。「主資料夾筆數」是這個索引，0 是第一張。某個曝光張數不夠時用該曝光最後一張，不會略過。較短的數字不會誤認成較長的，`500us` 不會變成 `5000us`。

載入或換點位後先跳出計算範圍。可選全屏、512×512 或自行輸入寬高後拖移。預覽沿用融合視窗目前的色表，色階用這張影像的最小到最大，背景留在黑色，光斑才進藍到白。確定後，單次計算和批次融合都只使用這一塊。「調整範圍」可以再選一次。清空會清掉檔案、點位列表、曝光列和這個範圍；下一次載入要重新選。

曝光表只顯示已匯入的曝光，由小到大排。認不出曝光時間的檔案不會載入。同一時間再載入會換掉該列的檔案。移除會刪掉該列。有檔案的列顯示檔名、尺寸、型別、最小到最大，右邊是曝光時間，單位 us。檔名是單列，滑鼠滾輪在檔名上左右捲動。取消勾選就排除那張。曝光時間要大於 0。

「清空」清掉全部檔案、點位與曝光列，以及計算範圍。

## 輸入前處理

計算前，每一張勾選的曝光先依序處理，再送進演算法。順序是：倍率 → 該張的 color scale → 高斯模糊 → 演算法。這三步會進浮點結果；匯出 npy 再乘滿量。倍率和 color scale 在左側每一列曝光上，各張分開設。高斯模糊在畫布左上角，每一張共用。改倍率、color scale 或高斯模糊時，若已經算過一次，會自動重算。畫布上的 log、abs 只重畫畫面。

每一列可填「加總平均」N：排序後每 N 張加總平均成一張，餘數丟掉；N 大於總張數會擋下；空白＝不採用。按「計算」時依「目前張數」取對應那一段，加總平均後只做一次融合。有勾「批次融合」時此欄暫不套用（仍依原始張數逐筆融合）。

### 倍率

每一列一個輸入，預設 1。這張曝光的像素先乘上這個數，再做後面的 color scale 和高斯模糊。

### color scale

每一列自己的下限和上限，預設留空。留空的那一側不採用。有填下限時，小於等於該值的像素改成 0。有填上限時，大於等於該值的像素改成該值。套在倍率之後、高斯模糊之前。

### 高斯模糊

在畫布左上角，可勾選，預設不勾。勾選後，每一張曝光在倍率和自己的 color scale 之後做 Gaussian blur。水平、垂直是核寬，預設都是 3，範圍 1–99。sigma 兩邊共用，預設 0.8，範圍 0.01–100。某一邊的核寬是 1 時，該方向不模糊。不勾時這三個輸入停用。滾輪滑過輸入框不改數值。

### log

可勾選，預設不勾。熱圖、色條、X 剖面、Y 剖面和 Y 累加改為 `log10`，直接作用在演算法的浮點結果上。Y 累加是先沿 X 加總線性值再取 log。峰值大於 1.5 時，小於 1 的值以 1 計算。Mertens 已乘 255，會走這條。只改畫面和匯出預覽，不改 npy。

## 畫面

熱圖背景是淺灰，有格線。畫布左上角是 log、abs、高斯模糊；色條上下限和七個色條三角留在畫布。每一列曝光另外有倍率和 color scale。色條上下限用一般小數；輸入完成後只改熱圖和色條的顯示範圍，不重算演算法。拖色條上的範圍時，這兩個框會跟著改。三角位置 0 在下方，1 在上方；拖三角時輸入框會跟著改。右邊色條下方是黑色、中間是藍、青、綠、黃、紅，上方是白色。彩色結果在畫面上用三個通道的平均顯示，色條對應這個平均。游標在畫布下方；讀數是演算法的浮點結果（已含高斯模糊和 color scale），不含 log；彩色時三個通道都列出來。

計算完成後，十字放在畫面最亮的像素。點熱圖可改位置。下方 X 剖面是該列。融合區可點「Y 剖面」或「Y 累加」，一次只會選一個。選中的按鈕是深色。Y 剖面曲線區的寬度和 X 剖面曲線區的高度相同。切換時外框大小不變，像素軸留在原本的範圍，強度軸改配到新的曲線。Y 剖面是十字所在那一行；Y 累加是計算範圍（512×512 ROI）內每一列沿 X 加總。分析畫布的 Y 加總則是粉紅條帶 ROI。有勾 log 時，累加是先加總線性值再取 log10。曲線上的圓點是十字那一點。剖面用的是目前畫面上的數值。有勾 log 時就是 log 後的值。滑鼠移到 X 剖面或左側曲線上時，數值窗放在該剖面圖的右上角；字太寬時整框留在畫面裡，不裁切。游標列也會顯示像素位置與強度。輸入框按 Ctrl+Z 會回到上一個確定的數值；正在打字時，Ctrl+Z 先收回剛打的字。

X 剖面的強度是縱軸，Y 側的強度是橫軸。勾 log 時軸名是「log10 強度」或「log10 累加強度」。點該軸的最小值可輸入下限，點最大值可輸入上限，用科學記號。下限必須小於上限。換十字、重新計算，或勾、取消 log 後，X 剖面和左側圖的強度軸都會改配到目前這條曲線。雙擊 X 剖面或左側圖，像素軸和強度軸都回到整段。雙擊熱圖，視野回到整張圖。雙擊色條，色階回到目前畫面的範圍：沒勾 log 時是資料最小到最大，有勾 log 時是 log 後的最小到最大。

結果文字寫演算法名稱、輻射圖或融合結果、形狀、最小和最大。有非有限值時會寫出個數。

## 匯出

計算成功後會自動把結果送進中間的分析區（仍留在融合畫面）。按「分析」會再送一次並切到分析畫面。數值是 × 255 之後的 8-bit 尺度，不含 log。兩種 Mertens 的浮點結果已經 × 255，直接送進去。Debevec、Robertson 和單張的浮點結果會再 × 255。彩色影像先取三個通道的平均。分析區的「匯出」選一個父資料夾後，會新建以目前點位命名的子資料夾，再寫入 `spots_時間戳.csv`、`strip_sum_raw_時間戳.csv`、`strip_sum_時間戳.csv`、`params_時間戳.json` 和熱圖。第一個 CSV 是光斑參數、位置和距離，後兩個分別是未扣中位數和已扣中位數的條帶加總。參數檔含條帶寬度、門檻、演算法和色條三角。熱圖不含色條和 ROI；批次時每一筆一張。送進分析時會帶入融合區目前的色條三角和色階。找點說明見 `dual_spot.md`。

「批次融合」在計算按鈕下方。勾選後用目前的演算法、倍率、color scale 和高斯模糊，依主資料夾每個曝光的排序，從第 0 筆融合到**張數最多**的那個曝光。張數較少的曝光固定重複用最後一張（只有一張時整批都用同一張）。進度條顯示第幾筆。融合中取消勾選會停下來，已完成的筆數仍留下。畫布顯示「主資料夾筆數」那一筆；超過範圍時顯示最後一筆。分析區左上方可改筆數，0 是第一張。切換時沿用條帶寬度、上下門檻和下光斑演算法。沒勾批次融合時，分析只看畫面上這一張。

按「匯出」選一個資料夾，一次寫出下面這些檔。檔名都是英文，並帶 `YYYYMMDD_HHMMSS`。寫完會跳出完成視窗。

| 檔案 | 內容 |
| --- | --- |
| `profiles_時間戳.csv` | 第一行是標題，曲線往右各成一欄。欄位是 `pixel`、`before_x`、`before_x_log10`、`before_y`、`before_y_log10`、`before_ysum`、`before_ysum_log10`，after 同樣六欄。before 是同一組輸入不做高斯模糊；after 是畫面上這次計算的結果。X、Y 剖面用目前十字的那一列和那一行。某條曲線比其他條短時，下方留空 |
| `heatmap_時間戳.png` | 畫布調整後的熱圖和兩張剖面。含目前色階、色條顏色、log 和左側剖面模式。不含色條，熱圖上不含十字 |
| `hdr_時間戳.npy` | Debevec、Robertson 和單張是浮點結果 × 目前滿量（預設 4095）。兩種 Mertens 的浮點結果已經 × 255，不再乘滿量。都不含 log |
| `params_時間戳.json` | 演算法和設定、高斯模糊核寬和 sigma、每一列的倍率和 color scale、log、色階、七個色條三角的位置、曝光檔和十字位置 |
